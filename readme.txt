Extra Elementor widgets for teams, services, pricing, galleries, testimonials, counters, and section titles.

== Description ==

Elemental Addons for Elementor adds content widgets to the Elementor editor. Each widget stores its own text and images, so it works on any theme, including Hello Elementor.

Widgets included:

* Team Block
* Testimonial Block
* Service Block
* Pricing Block
* Image Gallery
* Features Block
* Counter Block
* Accordion
* Animated Layers
* Clients Logo
* Contact Form 7
* Floating Objects
* Funfact Counter
* Progress Bar
* Section Title
* Text Editor
* Text Editor Advanced
* Theme Button
* List
* Icon Box
* Working Process Block
* Swiper Carousel Arrow
* Pricing Plan
* Blog / News Grid

Contact Form 7 is optional. The Contact Form widget shows a notice in the editor when Contact Form 7 is not active.

LightGallery 1.6.10 is included under GPLv3 for the image gallery lightbox.

Isotope 3.0.6 (https://isotope.metafizzy.co) by Metafizzy is included under GPLv3 for grid and masonry layouts.

Widget type IDs match the ThemeMascot Evolta Elementor widgets (tm-ele-*), so sections that only use supported widgets can be copied between sites. For full layouts that include unsupported widgets, use **Elemental Addons → Layout Converter**.

Enable or disable individual widgets from **Elemental Addons → Widgets Manager**.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/elemental-addons`, or install the zip from Plugins > Add New.
2. Activate Elementor, then activate Elemental Addons for Elementor.
3. Edit a page with Elementor and open the Elemental Addons category.

== Frequently Asked Questions ==

= Does this plugin require a theme? =

No. It runs with Elementor on any theme.

= Does the contact form widget require another plugin? =

Yes. Install the free Contact Form 7 plugin to use the Contact Form widget. The other widgets work without it.
